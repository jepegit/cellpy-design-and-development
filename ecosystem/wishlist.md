# Extensions & wishlist

Living scratchpad for **possible extensions**, nice-to-haves, and ideas that are
**not yet** committed Stage / milestone work.

Use this when dogfooding ([`cellpy-simple-gui`](https://github.com/cellpy/cellpy-simple-gui),
notebooks, real analyses) surfaces friction or inspiration. Promote an item into
a GitHub issue + Stage plan when it earns a place; leave it here while it is
still a maybe.

**Not the source of truth for scheduled work** — that is [`../CURRENT.md`](../CURRENT.md)
and the Stage issue sets under [`../roadmap/stages/`](../roadmap/stages/).

---

## How to add an entry

Copy a row (or a short subsection). Prefer one idea per bullet.

| Field | Hint |
|---|---|
| **Idea** | One-line name |
| **Why** | Pain point or opportunity (what broke / what felt missing) |
| **Where found** | e.g. `cellpy-simple-gui`, notebook, user report |
| **Likely home** | `cellpy` / `cellpycore` / GUI-only / docs / unsure |
| **Status** | `idea` · `needs-spike` · `issue-filed` · `wont` · `done` |
| **Links** | Issue / PR / related plan (optional) |
